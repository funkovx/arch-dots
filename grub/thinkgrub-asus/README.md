# ThinkGRUB ASUS compatibility entry point

The universal theme now lives in [../thinkgrub](../thinkgrub/README.md).
This directory keeps the original installation command working and forces
the white ASUS logo. The PNG in Downloads is unchanged.

Install on Arch Linux:

```sh
sudo ~/.dotfiles/grub/thinkgrub-asus/install.sh
```

For hardware detection, use `sudo ~/.dotfiles/grub/thinkgrub/install.sh`.
