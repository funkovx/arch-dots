# Screenshot capture list

Capture the current configuration after applying boot setup and rebooting.
Save desktop captures as PNG at native resolution. Use consistent dimensions
for the desktop gallery.

| File | Content |
| --- | --- |
| `docs/images/desktop.png` | Black desktop, complete Waybar, one Kitty window |
| `docs/images/quick-settings.png` | Open quick settings panel with the bar visible |
| `docs/images/launcher.png` | Centered monochrome Rofi application launcher |
| `docs/images/grub.png` | ASUS GRUB menu with the final font and layout |
| `docs/images/boot-splash.png` | Arch logo during boot, before the login prompt |
| `docs/images/login.png` | Tuigreet login screen |

Optional: `lock-screen.png`, `calendar.png`, `dolphin.png`.
For the calendar, show the highlighted current date.

GRUB and Plymouth require a photo or a frame from a boot video on the physical
laptop. A VM capture can document the theme separately but does not verify
firmware scaling. Tuigreet can also be photographed.

Close private windows. Exclude account details, credentials and personal
network names. Do not redraw interfaces or label mockups as screenshots.

Replace the previous gallery only after the new captures are available.
